# [Classforge]

Join our Discord Server: [https://discord.gg/5RtDbkY3fC](https://discord.gg/dkW2VAAe7s)

Biggest Changes:
* Class-based skill system.
  * Warrior
  * Mage
  * Cleric
  * Ranger
  * Rogue
* Equipment/items can be restricted based on class.
* No item insurance - all non-stackable/non-cursed items always remain with a character when they die.
* No races. Humans only.
* One map.
* A lot of systems were removed to provide a cleaner starting point to make new systems.
